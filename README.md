# Praise Change Divine Life Gospel Ministry Website

A modern, responsive church website developed for **Praise Change Divine Life Gospel Ministry**. The website serves as an online presence for the ministry, providing visitors with information about church programs, leadership, branch locations, and prayer support..

## ✨ Features

- Responsive and mobile-friendly design
- Modern UI built with Tailwind CSS
- Hero section with ministry introduction
- Pastor profile and ministry vision
- Weekly service schedule
- Church branch locations
- Prayer request submission form
- Mobile navigation menu
- Smooth scrolling experience
- Interactive user feedback notifications

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS (CDN)
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/praise-change-divine-life-website.git
```

### Open the Project

Simply open the `index.html` file in your browser.

No build tools, package managers, or installation steps are required.

## 📖 Website Sections

### Home
A welcoming hero section introducing visitors to the ministry.

### About Our Pastor
Features information about Pastor Emmanuel Gabriel and the ministry's vision.

### Our Programs
Displays weekly church services including:

- Sunday Service
- Bible Study
- Thursday Prayer Service

### Our Branches
Provides information about ministry locations and parishes.

### Prayer Request
Allows visitors to submit prayer requests through an interactive form.
